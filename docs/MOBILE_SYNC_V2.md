# 모바일 클라우드 동기화 — v2.0 (IT 인계용 메모)

## 현재(v1) 상태

- 모바일 레이아웃(≤700px)은 **조회 전용**입니다. 재고·입고·저장 API는 사용하지 않으며, 모바일에서 `localStorage`에 재고 스냅샷을 쓰지 않도록 분기되어 있습니다.
- **v1에서는 모바일 경로에서 클라우드 동기(pull/push)를 실행하지 않습니다.** 로그인 시 원격 부트스트랩 스플래시, 주기적 pull, 탭 전환 pull, 상단 동기 배너는 **PC 넓은 화면에서만** 표시·동작합니다.
- 모바일 헤더의 **「화면 새로고침」**은 `window.location.reload()`만 수행합니다(이미 로드된 앱·로컬 캐시 기준).

## v2.0에서 검토할 항목 (예시)

- 모바일에서 안전하게 **읽기 전용 pull**만 재도입할지(쓰기·push 금지 유지).
- 세션·토큰 노출 최소화, PWA·백그라운드 갱신 정책.
- 관리자(Admin)만 원격 설정 화면 접근 유지 vs 모바일 전용 상태 표시.

관련 코드: `src/App.jsx`(`isMobileWarehouseNav`), `src/utils/inventoryRemoteSync.js`, `docs/REMOTE_SYNC.md`.
